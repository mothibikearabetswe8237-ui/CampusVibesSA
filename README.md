1. Project Overview

Campus Vibes SA is a fictional student-focused organisation created for
an academic web development project.

The purpose of the website is to help college and university students
find information about campus events, sports, social activities, games
and student deals in one convenient place.

Students may normally receive campus information through WhatsApp
groups, social media and word-of-mouth. This can make it difficult to
find information quickly.

The Campus Vibes SA website provides a central online platform where
students can find important campus information.


2. Website Goals and Objectives

The main goal of the website is to create a simple and easy-to-use
online platform for students.

The website aims to:

- Raise awareness of campus events.
- Make campus information easier to find.
- Encourage students to participate in social activities.
- Encourage students to participate in sports.
- Provide information about student deals.
- Allow students to make enquiries.
- Create a professional online identity for Campus Vibes SA.


3. Target Audience

The main target audience is college and university students,
especially first-year students.

The website is designed for students who:

- Are new to campus.
- Want to meet other students.
- Want to find campus events.
- Are interested in sports.
- Are interested in games and social activities.
- Want to find student deals.

In Part 2, the Campus Vibes SA website was improved using CSS styling and responsive design.
The improvements listed below were put into effect:

-In order to adapt to various screen sizes, photos were made responsive.
-A 768px media query has been added for tablets and smaller devices.
-A 480-pixel mobile media query has been added.
-For smaller screens, navigation, typography, tables, forms, and buttons were modified.
-The website was tested on tablets, smartphones, and desktop computers.
